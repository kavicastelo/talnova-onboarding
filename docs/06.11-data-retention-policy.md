# Talnova Onboarding

# 06.11 — Data Retention Policy

---

# Purpose

Control storage growth while maintaining compliance.

---

# Organizations

Retention:

```text
Permanent
```

---

# Users

Retention:

```text
Permanent
```

Soft delete only.

---

# Journeys

Retention:

```text
Permanent
```

Archived journeys remain available.

---

# Assignments

Retention:

```text
7 years
```

---

# Notifications

Retention:

```text
180 days
```

TTL Index:

```ts
{
 expiresAt:1
}
```

---

# Uploads

Retention:

```text
Permanent
```

Deleted uploads:

```text
30 day recovery window
```

---

# Audit Logs

Retention:

```text
7 years
```

Enterprise:

```text
Custom retention
```

---

# Export Policy

Organizations can export:

* Employees
* Assignments
* Journeys
* Audit Logs

Formats:

```text
CSV
JSON
PDF
```

---

# GDPR Support

Support:

```text
Data export

Data deletion

Anonymization
```

Personal data can be anonymized without destroying audit records.
