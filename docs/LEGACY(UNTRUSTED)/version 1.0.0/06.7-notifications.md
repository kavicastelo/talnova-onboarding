# Talnova Onboarding

# 06.7 — Notifications Collection

**Collection Name**

```text
notifications
```

---

# Purpose

The Notifications collection manages all system-generated and user-targeted communications within the onboarding platform.

Notifications are used for:

* Journey assignments
* Journey reminders
* Due date alerts
* Journey completion alerts
* Team announcements
* Organization-wide announcements
* Knowledge base updates
* Employee invitations
* Manager alerts
* System alerts

This collection serves as the central notification center for employees, managers, admins, and organization owners.

---

# Design Principles

Notifications must support:

* In-app notifications
* Email notifications
* Future push notifications
* Future Slack/MS Teams integrations
* Read/unread tracking
* Delivery tracking
* Retry handling
* Bulk notifications

Notifications should be immutable after delivery except for status updates.

```ts

  type: "journey_assigned"
}
```

---

  type: "journey_due_soon"

{

# Read Tracking

Employees can mark notifications as read.

```ts
{
  isRead: true,
  readAt: ISODate()
}
```

Unread count powers:

* Header notification badge
* Dashboard alerts
* Mobile badge counts

# Query Patterns

Get employee notifications:

```ts
db.notifications.find({
  recipientUserId
})
.sort({
  createdAt: -1
})
```

---

Unread notifications:

```ts
db.notifications.find({
  recipientUserId,
  isRead: false
})
```

---

Notification count:

```ts
db.notifications.countDocuments({
  recipientUserId,
  isRead: false
})
```

---

Retry failed notifications:

```ts
db.notifications.find({
  status: "failed",
  retryCount: {
    $lt: 5
  }
})
```
