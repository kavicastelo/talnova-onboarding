# Talnova Onboarding — Engineering Audits & Investigation Archive

> **Directory Purpose:** This directory contains historical engineering audits, system investigation logs, codebase ground-truth trace reports, phase completion reports, and test evidence files.
> 
> **Important Note for AI Agents & Developers:**  
> The documents in this directory represent **historical implementation state investigations** and engineering records. They are **NOT** authoritative product requirements.
> 
> For canonical product specifications, domain models, business rules, and unified requirements, refer exclusively to [`docs/product/`](../product/README.md).

---

## Directory Navigation

### 1. `archive/engineering_audits/`
Contains root-level forensic audits, process-flow traces, codebase ground-truth analyses, event outbox contracts, and requirement failure investigations:
- Executive summary logs
- Repository maps & flow diagrams
- Canonical state machine audits
- Acceptance scenario reviews

### 2. `archive/legacy_v1/`
Contains historical technical specifications from the original V1.0.0 architecture:
- Database schema drafts and relation tables
- Backend service breakdowns
- Original public kiosk journey specification

### 3. `archive/legacy_v2/`
Contains historical phase implementation reports, test evidence summaries, and API contracts for Phases 1 through 19:
- Phase contracts (`PHASE-X-API-CONTRACT.md`)
- Implementation reports (`PHASE-X-IMPLEMENTATION-REPORT.md`)
- Test evidence files (`PHASE-X-TEST-EVIDENCE.md`)
- Forensic audit reports (`TALNOVA_ONBOARDING_FEATURE_AUDIT.md`, `TALNOVA_BROWSER_PROCESS_FLOW_FORENSIC_AUDIT.md`)

### 4. `current/`
Directory reserved for ongoing runtime trace logs and active system audit outputs.
