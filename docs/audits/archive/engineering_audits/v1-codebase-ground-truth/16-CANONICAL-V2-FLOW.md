**INTENDED (requirements/code signals):** employee creation → rules/targeting → journey and operational resources → employee execution → completion/handover.

**RECOMMENDED:** employee intake → one durable onboarding case → deterministic plan resolution → idempotent resource materialisation → active execution → aggregation of explicit required gates → persistent authorised handover → completed. This is a recommendation, not a statement of current runtime.
