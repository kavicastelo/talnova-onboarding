# Talnova Onboarding

# 06.9 — System Settings Collection

Collection Name

```text
systemSettings
```

---

# Purpose

Stores organization-level configuration that should not be embedded inside the organization document.

This collection contains:

* Feature flags
* Email settings
* Branding settings
* Default onboarding settings
* AI settings
* Integration settings
* Future enterprise settings

One document per organization.

---

```ts
{
  _id: ObjectId,

  notifications: {

  updatedAt
}
```
