# 06.3 — Journeys Collection

**Collection Name**

```text
journeys
```

---

# Purpose

The Journey aggregate is the core learning and onboarding engine of Talnova.

A Journey represents a complete onboarding experience that employees must complete.

Examples:

* New Employee Onboarding
* Engineering Team Onboarding
* Sales Team Onboarding
* Security Awareness Training
* Compliance Training
* Leadership Onboarding
* Product Knowledge Training

A Journey contains:

* Metadata
* Modules
* Lessons
* Content Blocks
* Quizzes
* Completion Rules
* Certificate Configuration
* Publishing Settings
* Analytics Snapshots

MongoDB is optimized here by embedding the entire course structure inside a single document.

  _id: ObjectId,

# Module Schema

Modules group lessons together.

Example:

```text
Welcome Module

Company Overview Module

Security Module

Benefits Module
```

Schema:

```ts
{
  _id: ObjectId,

  title: string,

  description?: string,

  order: number,

  estimatedDurationMinutes: number,

  lessons: Lesson[]
}
```

---

# Lesson Schema

A lesson is the smallest learning unit.

Examples:

```text
Welcome Video

CEO Message

Security Policies

Benefits Guide
```

Schema:

```ts
{
  _id: ObjectId,

  title: string,

  description?: string,

  order: number,

  estimatedDurationMinutes: number,

  contentBlocks: ContentBlock[],

  attachments: Attachment[],

  quiz?: Quiz,

  completionRules: {

    requireContentCompletion: boolean,

    requireQuizCompletion: boolean,

    minimumQuizScore?: number

  }
}
```

# Upload References

Journey content never stores actual files.

Only references:

```ts
{
  uploadId: ObjectId
}
```

Files are stored in:

```text
Cloudflare R2
```

Metadata stored in:

```text
uploads collection
```

# Versioning Strategy

Every published update increments:

```ts
publishing.version
```

Example:

```text
Version 1

Version 2

Version 3
```

Assignments always record:

```ts
assignedJourneyVersion
```

This ensures historical progress remains accurate.

# MongoDB Size Considerations

MongoDB document limit:

```text
16 MB
```

To stay safe:

Recommended limits:

```text
Max Modules: 50

Max Lessons per Module: 100

Max Content Blocks per Lesson: 50

Max Quiz Questions per Lesson: 100
```

Large videos and PDFs are never stored inside documents.

Only R2 references are stored.

# Journey Aggregate Boundaries

The Journey aggregate owns:

```text
Journey Metadata

Modules

Lessons

Content Blocks

Quizzes

Completion Rules

Publishing Settings

Certificate Settings
```

The Journey aggregate does NOT own:

```text
Employee Progress

Assignments

Certificates

Uploads

Notifications
```

Those belong to separate collections and aggregates.
