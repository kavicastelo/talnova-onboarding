# 06.4 — Employee Assignments Collection

**Collection Name**

```text
employeeAssignments
```

---

# Purpose

The Employee Assignment collection is the operational heart of the onboarding platform.

While Journeys define the onboarding content, Employee Assignments track the real-world execution of onboarding for every employee.

This collection stores:

* Journey assignments
* Employee progress
* Lesson completion
* Quiz attempts
* Quiz scores
* Completion status
* Time tracking
* Due dates
* Certificates
* Manager reporting metrics

This collection becomes the primary source for:

* Employee dashboards
* Manager dashboards
* HR analytics
* Executive reporting
* Completion reports

---

# Why Separate Collection?

Employee progress changes frequently.

A Journey document may be read thousands of times.

Embedding progress inside Journeys would create:

```text
Large document growth

Write contention

Poor scalability

Expensive updates
```

Instead:

```text
Journey = Content

EmployeeAssignment = Progress
```

This follows MongoDB best practices.

# Completion Logic

Assignment becomes completed when:

```text
All Required Modules Completed

AND

All Required Lessons Completed

AND

All Required Quizzes Passed
```

Defined by Journey rules.

---

# Progress Calculation

Formula:

```ts
completionPercentage =
(
  completedLessons /
  totalLessons
) * 100
```

Rounded:

```ts
Math.round(percentage)
```

# Aggregate Ownership

Employee Assignment owns:

```text
Progress

Lesson Completion

Quiz Attempts

Time Tracking

Completion Status

Certificate References
```

Employee Assignment does NOT own:

```text
Journey Content

Uploads

Users

Notifications

Audit Logs
```

Those remain in separate collections.

---

# Collection Cardinality

Expected largest collection in platform.

Example:

```text
100 Organizations

500 Employees Each

20 Assigned Journeys Each

=
1,000,000 Assignment Documents
```

MongoDB Atlas handles this efficiently with proper indexing.

This collection should be treated as a high-write workload collection.
